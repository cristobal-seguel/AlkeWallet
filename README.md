## Descripción

El proyecto es una pequeña aplicación web que simula operaciones básicas de banca/transferencias: inicio de sesión, depósito, envío de dinero y visualización de transacciones. Para el frontend se utiliza el Framework Boostrap, se utiliza el paradigma de programacion orientada a objetos a través del uso de clases, y se realiza persistencia de datos en el almacenamiento del navegador.


## Estructura del proyecto

- **Archivos HTML**: `index.html`, `login.html`, `deposit.html`, `sendmoney.html`.
- **Archivos JavaScript**: `assets/js/index.js`, `assets/js/login.js`, `assets/js/deposit.js`, `assets/jssendmoney.js`,`assets/js/clases/Usuario.js`, `assets/js/clases/Wallet.js`.
- **Archivos JSON**: `usuarios.json`.


## Descripción de las páginas

- `login.html`: Formulario de acceso.
- `index.html`: Página principal / dashboard.
- `deposit.html`: Interfaz para simular depósitos.
- `sendmoney.html`: Formulario para enviar dinero entre cuentas.

## Requisitos

- Navegador moderno (Chrome, Edge, Firefox).
- No requiere backend — puede abrirse directamente en el navegador o servir con un servidor HTTP estático.

## Cómo ejecutar

1. Abrir `index.html` directamente en el navegador (modo local) o usar un servidor estático.

## Notas de uso

- Las funcionalidades (login, depósitos, envíos) están simuladas en el cliente con JavaScript y no persisten en un servidor.
- Revisar `assets/js/` para ver la lógica asociada a cada página.
